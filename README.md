# kirara-to-x-poster

このリポジトリは、学習管理サービス「KIRARA」の記事から内容を抽出し、X(旧Twitter)で共有するためのChrome拡張です。ポップアップを開くと、ページ内の情報を取得し、投稿用のテキストを生成します。文字数カウント機能を備えており、280文字以内かどうかを確認できます。

## セットアップ
1. リポジトリをクローン後、依存パッケージをインストールします。
   ```bash
   npm install
   ```
2. `browserify`を用いてライブラリをバンドルします。
   ```bash
   npm run build
   ```
3. Chromeの拡張機能管理ページ(`chrome://extensions/`)でデベロッパーモードを有効にし、`Load unpacked`から本リポジトリを選択します。

## 使い方
1. KIRARAで記事ページを表示した状態で拡張機能のアイコンをクリックします。
2. ポップアップに抽出された内容が表示されます。内容を確認し、必要に応じて編集します。
3. `Xへ投稿`ボタンを押すと、新しいタブでXの投稿画面が開き、生成されたテキストが挿入されます。

## スクリプト
- `npm run build` : `src/twitter-text-module.js` をブラウザ用にバンドルし、`dist/twitter-text-bundle.js`を生成します。
